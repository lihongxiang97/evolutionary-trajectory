# Analysis-result inventory

This directory contains compact intermediate and final statistical results
that support the manuscript beyond the plotting tables.

- `3D_duplicate_mechanisms/`: integrated gene and duplicate-pair features,
  regulatory-capture models, TAD co-residence tests and hapA–hapB pair-level
  cross-haplotype robustness analysis.
- `Cross_Haplotype_Robustness/`: reciprocal-best-hit mapping features,
  continuous and binary concordance, Young–Old effects and adjusted hapB
  models.
- `Risk_Audit/`: transposable-element annotation, gene-level overlap and
  TE-adjusted sensitivity models.
- `Completion_Markers/`: completion records for the hapB Hi-C, ATAC, RNA,
  3D-genome and cross-haplotype workflows.

Large primary read alignments and Hi-C matrices are not stored in GitHub.
